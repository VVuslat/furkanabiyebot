# furkanabiyebot

Scalping stratejisi için güncel piyasa verisini okuyup EMA/RSI/ATR ve Markov zinciriyle
sinyal üreten basit bir web uygulaması.

## Kurulum

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Çalıştırma

```bash
python app.py
```

Ardından tarayıcıda `http://localhost:8000` adresini açın.
